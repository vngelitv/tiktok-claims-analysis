# Course 3 – Statistical Analysis

This folder contains the statistical analysis phase of the TikTok Claims Analysis project.

## Work Completed

- Reviewed descriptive statistics
- Examined missing values
- Compared video view counts by verification status
- Formulated null and alternative hypotheses
- Conducted a two-sample t-test
- Evaluated statistical significance at the 5% level
- Interpreted findings for stakeholders

## Key Finding

The hypothesis test found a statistically significant difference in average video view counts between verified and unverified TikTok accounts.

The p-value was approximately `2.61e-120`, which is far below the 0.05 significance level, so the null hypothesis was rejected.
